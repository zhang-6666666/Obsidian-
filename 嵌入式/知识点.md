## **ISR** 
是 **Interrupt Service Routine**（中断服务函数）的缩写
## 中断服务函数
```c
void USART2_IRQHandler(void)
{
    // 只要产生中断，都会到达这个中断服务函数
    HAL_UART_IRQHandler(&huart2);
}
```
`HAL_UART_IRQHandler(&huart2);`
1. 检查中断源
2. 接收中断：`HAL_UART_RxCpltCallback()` 回调函数
发送中断`HAL_UART_TxCpltCallback()` 回调函数
错误中断`HAL_UART_ErrorCallback()` 回调函数
3. 清除中断标志位
中断回调函数才是需要处理的地方，常见做法是置标志位，绝对不能执行耗时任务！

例如，对于[[空闲中断+DMA+环形缓冲区]]来说
当RX线空闲超过一字节时，IDLE置位,触发IRQHandler中断函数
