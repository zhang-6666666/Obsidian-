#### 工作流程
串口中断解析（效率最低，实现最简单）用于测试工程
```c#
/* printf 重定向到 USART1，newlib-nano 要求实现 __io_putchar */
int __io_putchar(int ch)
{
    HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, 10);
    return ch;
}
```

`wit_c_sdk.c`协议状态机
每次直接移植，不需要修改
static uint8_t s_ucWitDataBuff[WIT_DATA_BUFF_SIZE];理解为缓冲区，所有的数据被存储在这里面
`void WitSerialDataIn(uint8_t ucData);`状态机函数，当接收中断触发时调用,寻找0x55帧头并不断拼接数据包，直到满足11位数据,经过校验和，拼接字符串第八位和高八位成一个完整的两字节,标志位置1，打印数据



#### DMA + 环形缓冲区 + IDLE 中断

1. 环形缓冲区`ringbuf.h`(0依赖，可移植到任意的项目中！)
`ringbuf_t`结构体
`ringbuf_init`结构体初始化
`ringbuf_put`在中断中写入数据
`ringbuf_get`在主循环中轮询读取数据，返回实际读取的字节数
`uint32_t ringbuf_available(ringbuf_t *rb);`
`uint32_t ringbuf_free(ringbuf_t *rb);`
