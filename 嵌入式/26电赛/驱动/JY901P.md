## DMA + 环形缓冲区 + IDLE 中断

1. 环形缓冲区`ringbuf.h`(0依赖，可移植到任意的项目中！)
```c

typedef struct {

    uint8_t *buffer;           // 静态数组指针

    uint32_t size;             // 自动对齐到 2 的幂

    volatile uint32_t head;    // ISR 写指针

    volatile uint32_t tail;    // 主循环读指针

} ringbuf_t;


void     ringbuf_init(ringbuf_t *rb, uint8_t *buf, uint32_t size);

uint32_t ringbuf_put(ringbuf_t *rb, const uint8_t *data, uint32_t len);   // ISR 侧

uint32_t ringbuf_get(ringbuf_t *rb, uint8_t *out, uint32_t len);          // 主循环侧

uint32_t ringbuf_available(ringbuf_t *rb);

uint32_t ringbuf_free(ringbuf_t *rb);

```

###  环形缓冲（ringbuf）

```c

typedef struct {

    uint8_t *buffer;           // 静态数组指针

    uint32_t size;             // 自动对齐到 2 的幂

    volatile uint32_t head;    // ISR 写指针

    volatile uint32_t tail;    // 主循环读指针

} ringbuf_t;

  

void     ringbuf_init(ringbuf_t *rb, uint8_t *buf, uint32_t size);

uint32_t ringbuf_put(ringbuf_t *rb, const uint8_t *data, uint32_t len);   // ISR 侧

uint32_t ringbuf_get(ringbuf_t *rb, uint8_t *out, uint32_t len);          // 主循环侧

uint32_t ringbuf_available(ringbuf_t *rb);

uint32_t ringbuf_free(ringbuf_t *rb);

```

**特性**：单生产者单消费者 · 无锁 · head/tail 只增不减（uint32_t 自然回绕） · 取模用 `&(size-1)` 代替 `%`

### 5.3 SDK 配置命令（wit_c_sdk）

  

```c

// 输出内容控制

WitSetContent(RSW_ANGLE);            // 只输出角度（提速 4~5 倍）

WitSetContent(RSW_ACC | RSW_ANGLE);  // 加速度 + 角度

  

// 刷新率

WitSetOutputRate(RRATE_10HZ);   // 10Hz（默认）

WitSetOutputRate(RRATE_50HZ);   // 50Hz

WitSetOutputRate(RRATE_100HZ);  // 100Hz

WitSetOutputRate(RRATE_200HZ);  // 200Hz

  

// 滤波带宽（越大响应越快，噪声越大）

WitSetBandwidth(BANDWIDTH_256HZ);  // 响应最快

WitSetBandwidth(BANDWIDTH_20HZ);   // 平衡

WitSetBandwidth(BANDWIDTH_5HZ);    // 最平滑

  

// 波特率（改完后传感器保存，重新上电生效）

WitSetUartBaud(WIT_BAUD_115200);   // 升到 115200

  

// 校准

WitStartAccCali();  // 加速度校准（模块水平静置）

WitStopAccCali();

WitStartMagCali();  // 磁场校准（三轴慢转）

WitStopMagCali();
```

## 7. 注意事项

  

- **printf 浮点**：newlib-nano 默认不支持 `%f`，本项目所有角度计算和打印全部使用整数运算（×10 后拆整数和小数位）

- **Yaw 是绝对值**：0° = 磁北极，断电重启方向不变；受磁场环境影响（金属、大电流）

- **DMA 循环模式**：`dma_buf[64]` 大小必须是 2 的幂，否则 IDLE 中断中的 `&mask` 取模失效

- **IDLE 中断**：STM32F1 的 HAL 默认不使能 IDLEIE，需在 `jy901p_init` 中手动 `__HAL_UART_ENABLE_IT(huart, UART_IT_IDLE)`

- **CubeMX 重新生成**：`cmake/stm32cubemx/CMakeLists.txt` 会被覆盖，用户源文件路径写在根 `CMakeLists.txt` 中
