## 1. 数据流
```

JY901P 传感器 ──9600bps──→ PA3 (USART2_RX)

                              │

                    DMA1_Channel6 循环模式

                    自动写入 dma_buf[64]  ← CPU 零开销

                              │

                    一帧发完 → RX 空闲 1 字节时间

                    触发 USART IDLE 中断

                              │

                    ┌── jy901p_uart_isr() ──┐

                    │ 计算 DMA 增量            │

                    │ 逐字节写入 ringbuf       │

                    └─────────────────────────┘

                              │

                    ┌── jy901p_poll() ──────┐

                    │ 从 ringbuf 读字节        │

                    │ 逐字节喂 WitSerialDataIn │

                    │ 状态机拼接 11 字节帧      │

                    │ 校验通过 → sReg[]        │

                    │ 回调中预格式化角度字符串   │

                    └─────────────────────────┘

                              │

                    main 循环 1 行搞定:

                    printf("%s\r\n", jy901p_angle_str());

```

## 工作流程
串口中断解析（效率最低，实现最简单）用于测试工程
```c#
/* printf 重定向到 USART1，newlib-nano 要求实现 __io_putchar */
int __io_putchar(int ch)
{
    HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, 10);
    return ch;
}
```

`wit_c_sdk.c`协议状态机
每次直接移植，不需要修改
static uint8_t s_ucWitDataBuff[WIT_DATA_BUFF_SIZE];理解为缓冲区，所有的数据被存储在这里面
`void WitSerialDataIn(uint8_t ucData);`状态机函数，当接收中断触发时调用,寻找0x55帧头并不断拼接数据包，直到满足11位数据,经过校验和，拼接字符串第八位和高八位成一个完整的两字节,标志位置1，打印数据



## DMA + 环形缓冲区 + IDLE 中断

### 1. 环形缓冲区`ringbuf.h`(0依赖，可移植到任意的项目中！)
```c

typedef struct {

    uint8_t *buffer;           // 静态数组指针

    uint32_t size;             // 自动对齐到 2 的幂

    volatile uint32_t head;    // ISR 写指针

    volatile uint32_t tail;    // 主循环读指针

} ringbuf_t;


void     ringbuf_init(ringbuf_t *rb, uint8_t *buf, uint32_t size);

uint32_t ringbuf_put(ringbuf_t *rb, const uint8_t *data, uint32_t len);   
// ISR 侧 在中断中将dma硬件缓冲区的数据放入软件环形缓冲区

uint32_t ringbuf_get(ringbuf_t *rb, uint8_t *out, uint32_t len);          
// 主循环侧

uint32_t ringbuf_available(ringbuf_t *rb);

uint32_t ringbuf_free(ringbuf_t *rb);

```

### 2. `JY901_P`陀螺仪驱动API
```c
//封装使用的串口，以后直接使用j_huart和j_hdma_rx代替,便于移植
void jy901p_init(UART_HandleTypeDef *huart, DMA_Han leTypeDef *hdma_rx);

//在空闲中断中，将dma硬件缓冲区的数据搬运到软件环形缓冲区,并清除IDLE标志位
void jy901p_uart_isr(UART_HandleTypeDef *huart);

//从软件缓冲区中取出字节喂给SDK状态机，组装成一帧完整数据
void jy901p_poll(void);

// 返回非 0 表示有新角度
uint8_t jy901p_angle_ready(void);

void jy901p_read_angle(int32_t *roll_10, int32_t *pitch_10, int32_t *yaw_10);

// 预格式化字符串，如 "Roll=-1.8 Pitch=+0.7 Yaw=132.9"
const char *jy901p_angle_str(void);

```

### 3. SDK 配置命令（wit_c_sdk）


```c

// 输出内容控制

WitSetContent(RSW_ANGLE);            // 只输出角度（提速 4~5 倍）

WitSetContent(RSW_ACC | RSW_ANGLE);  // 加速度 + 角度

  

// 刷新率

WitSetOutputRate(RRATE_10HZ);   // 10Hz（默认）

WitSetOutputRate(RRATE_50HZ);   // 50Hz

WitSetOutputRate(RRATE_100HZ);  // 100Hz

WitSetOutputRate(RRATE_200HZ);  // 200Hz

  

// 滤波带宽（越大响应越快，噪声越大）

WitSetBandwidth(BANDWIDTH_256HZ);  // 响应最快

WitSetBandwidth(BANDWIDTH_20HZ);   // 平衡

WitSetBandwidth(BANDWIDTH_5HZ);    // 最平滑

  

// 波特率（改完后传感器保存，重新上电生效）

WitSetUartBaud(WIT_BAUD_115200);   // 升到 115200

  

// 校准

WitStartAccCali();  // 加速度校准（模块水平静置）

WitStopAccCali();

WitStartMagCali();  // 磁场校准（三轴慢转）

WitStopMagCali();

```
