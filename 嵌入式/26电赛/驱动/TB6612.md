# TB6612 电机驱动 — 移植计划

## 背景

在两轮差速小车项目中驱动直流电机。使用 TB6612 双路电机驱动芯片，两路 PWM 都在 TIM1 上（共用时基）。现有架构（ringbuf / jy901p / wit_c_sdk）已稳定，电机模块采用同样低耦合模式放入 `App/MOTOR/`。

## 硬件接线

| STM32 引脚 | 外设功能        | TB6612 引脚 | 说明          |
| -------- | ----------- | --------- | ----------- |
| PB13     | GPIO Output | AIN1      | 电机 A 方向 1   |
| PB12     | GPIO Output | AIN2      | 电机 A 方向 2   |
| PA11     | TIM1_CH4    | PWMA      | 电机 A 速度 PWM |
| PB14     | GPIO Output | BIN1      | 电机 B 方向 1   |
| PB15     | GPIO Output | BIN2      | 电机 B 方向 2   |
| PA8      | TIM1_CH1    | PWMB      | 电机 B 速度 PWM |

STBY 脚如使用，额外拉一个 GPIO；不拉则接 3.3V（常使能）。

## TB6612 控制逻辑

|IN1|IN2|PWM|结果|
|---|---|---|---|
|0|0|x|停止（滑行）|
|1|0|0~100%|正转，速度 = PWM 占空比|
|0|1|0~100%|反转，速度 = PWM 占空比|
|1|1|x|刹车（短接制动）|
## CubeMX 配置

1. 打开 `JY901P.ioc`
2. **Timers → TIM1**：
    - Clock Source: Internal Clock
    - **Channel 1**: PWM Generation CH1（输出到 PA8）
    - **Channel 4**: PWM Generation CH4（输出到 PA11）
    - Prescaler = **72-1**（72MHz/72=1MHz→1μs 计数精度）
    - Counter Period = **999**（1MHz/1000=1kHz PWM 频率）
3. 左侧 Pinout 视图，配置以下脚为 **GPIO_Output**：
    - PB12, PB13, PB14, PB15
4. 点击 **GENERATE CODE**

CubeMX 将自动生成 `MX_TIM1_Init()`（初始化 PWM）和对应的 GPIO 初始化代码。
