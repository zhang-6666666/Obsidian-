# 01studio
## 固件版本:
固件 (Firmware)

指运行在硬件上的程序本身。狭义上就是那段二进制代码，比如 K230 上跑的 CanMV MicroPython、RT-Smart 内核、U-Boot 等软件的集合。它是"内容"。

镜像 (Image)

指固件的存储/分发形式——一个完整的二进制文件，可以直接烧录到存储介质（SD 卡、eMMC 等）。它包含了分区表、引导程序、内核、文件系统等所有内容。

类比

镜像 : 固件  ≈  ISO文件 : 操作系统  ≈  安装包 : 软件

镜像是个容器/文件（比如 sysimage-sdcard.img.gz），固件是镜像里面装的程序代码。

实际上

在 K230 的语境下，大家说"烧录固件"和"烧录镜像"基本是同一回事——下载那个 .img.gz 文件，用 Rufus/dd 写到 SD 卡。所以日常交流中混用也没问题。
