
```
docker run -d \
  --name micro-ros-agent \
  --restart unless-stopped \
  --network host \
  registry.cn-hangzhou.aliyuncs.com/fishros/micro-ros-agent:humble \
  udp4 --port 8888 -v6
```
解释：
- `docker run`：创建并启动容器。
- `-d`：后台运行。
- `--name`：命名为 `micro-ros-agent`。
- `--restart unless-stopped`：开机自动启动。
- `--network host`：直接使用电脑网络。
- 镜像名称：提供 ROS 2 Humble 的 micro-ROS Agent。
- `udp4`：使用 UDP IPv4。
- `--port 8888`：监听 ESP32 的8888端口。
- `-v6`：输出详细日志。
