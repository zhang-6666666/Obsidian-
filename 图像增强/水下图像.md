# 解决方法：
1. 经典的图像增强与复原理论:
	1. 对比度增强技术
	2. 基于 Retinex的方法
	3. 多尺度融合策略
	4. 基于物理先验的方法,如暗通道先验和颜色线模型
	5. 基于水下光学成像的方法
	问题：
	复杂的水下环境中,泛化能力有限
	严重依赖于对水相关参数的准确估计
2. 深度学习：
	1. 基于卷积神经网络(CNNs)的端到端增 强方法已成为水下图像增强的主流方法
	2. 生成对抗网络(GANs)被 引入水下图像增强领域
	3. Transformer架构因其自注意力机制能够有效建模全局依赖 关系,已被应用于水下增强任务
	4. 基于结构化状态空间模型(SSMs)构建的Mamba架 构以线性复杂度实现长程建模(Lin等,2024),在性能与效率之间提供 了更好的平衡,已成为该领域一个有前景的方向
