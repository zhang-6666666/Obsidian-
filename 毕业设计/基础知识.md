## 通信链路与socket网络编程
### TCP（Transmission Control Protocol，传输控制协议）
	是一种面向连接的、可靠的、基于字节流的通信协议，是互联网协议套件中的核心协议之一。它运行在传输层，主要用于提供端到端的可靠通信。
	三次握手是TCP协议用于建立连接的过程，目的是确保客户端和服务器之间可以双向通信。三次握手的具体步骤如下：

- **第一次握手**（SYN）：
    
    客户端发送一个带有SYN（Synchronize Sequence Numbers）标志位的数据包给服务器，表示请求建立连接。此时，客户端进入SYN-SENT状态。
    
- **第二次握手**（SYN-ACK）：
    
    服务器收到SYN包后，回复一个带有SYN和ACK（Acknowledgment）标志位的数据包，表示同意建立连接，并对客户端的SYN包进行确认。此时，服务器进入SYN-RECEIVED状态。
    
- **第三次握手**（ACK）：
    
    客户端收到服务器的SYN-ACK包后，再发送一个ACK包给服务器，表示确认连接已经建立。此时，客户端和服务器都进入ESTABLISHED状态，完成三次握手。
### UDP（User Datagram Protocol，用户数据报协议)
	是互联网协议套件中的一种传输层协议，与广泛使用的TCP相比，它是一种**无连接**、**不可靠**的协议。UDP 被用于对==**传输速度要求较高**==、但对可靠性要求较低的场景。

## JSON是谁？
	**JSON（JavaScript Object Notation)**
	是一种轻量级的数据交换格式，常用于将数据结构化地传输和存储。它由**键值对**组成，采用类似于JavaScript对象的格式来表示数据。JSON易于阅读和编写，并且易于解析和生成，成为广泛应用于Web应用程序和数据交换的标准格式之一。
## mDNS
用于解决ip的动态变化问题
	**多播DNS（Multicast DNS，简称mDNS**）
	是一种用于局域网中**解析主机名**的协议，它允许网络设备在没有传统DNS服务器的情况下自行**发布和解析域名**。
	通常mDNS允许设备在局域网中以人类易读的名称（通常以.local结尾）被发现和访问，无需集中式的DNS服务器。这极大地简化了局域网中设备的发现和连接过程。
	mDNS的主要目标是简化小型网络（如家庭或小型办公室网络）的配置和使用，使设备可以通过名称而非IP地址进行通信。
	
| 类型           | 解释                                                             | 案例                                                |
| ------------ | -------------------------------------------------------------- | ------------------------------------------------- |
| 字符（String）   | 由双引号包围的 Unicode 字符序列                                           | `"Hello, World!"`                                 |
| 数字（Number）   | 包括整数和浮点数                                                       | `42`，`3.14`                                       |
| 布尔值（Boolean） | 表示真或假，C 相关的实现库可能会用 `0` 和 `1` 表示                                | 值为 `true` 或 `false`                               |
| 空值（Null）     | 表示空值                                                           | 值为 `null`                                         |
| 对象（Object）   | 由一组无序的键值对组成，键是字符串，值可以是任意 JSON 数据类型；键值对之间用逗号分隔，整个对象用花括号 `{}` 包围 | `{"name": "John", "age": 30, "city": "New York"}` |
| 数组（Array）    | 由一组有序的值组成，值可以是任意 JSON 数据类型；值之间用逗号分隔，整个数组用方括号 `[]` 包围           | `[1, 2, 3, 4, 5]`                                 |
