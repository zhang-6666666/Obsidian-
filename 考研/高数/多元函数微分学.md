# 多元函数微分学

---

## 一、基本概念

### 1. 连续

> **定义**：若 $\displaystyle\lim_{\substack{x \to x_0 \\ y \to y_0}} f(x, y) = f(x_0, y_0)$，则 $f(x, y)$ 在 $(x_0, y_0)$ 连续；若 $f(x, y)$ 在区域 $D$ 上每一点都连续，则称 $f(x, y)$ 在 $D$ 连续。

---

### 2. 偏导数

#### (1) 定义

若 $$\displaystyle\lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x, y_0) - f(x_0, y_0)}{\Delta x}$$ 存在，称此极限为 $f(x, y)$ 在 $(x_0, y_0)$ 处对 $x$ 的偏导数。

记作：
$$\frac{\partial z}{\partial x}\Big|_{(x_0, y_0)} \quad \text{或} \quad f'_x(x_0, y_0)$$

即：
$$f'_x(x_0, y_0) = \lim_{x \to x_0} \frac{f(x, y_0) - f(x_0, y_0)}{x - x_0} = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x, y_0) - f(x_0, y_0)}{\Delta x}$$

#### (2) 偏导函数

如果 $z$ 对区域 $D$ 上每一点 $(x, y)$ 都有偏导数，则一般而言，仍是 $x, y$ 的函数，称为 $f(x, y)$ 的偏导函数，记作：

$$\frac{\partial z}{\partial x},\quad \frac{\partial f}{\partial x},\quad f'_x(x, y),\quad \frac{\partial f(x, y)}{\partial x}$$

#### (3) 几何意义

（略）

#### (4) 高阶偏导数

对于 $z = f(x, y)$ 的一阶偏导数 $f'_x(x, y)$、$f'_y(x, y)$，若仍具有偏导数，则称其为二阶偏导数。

$$\frac{\partial^2 z}{\partial x^2} = \frac{\partial}{\partial x}\left(\frac{\partial z}{\partial x}\right) = f''_{xx}(x, y) = \frac{\partial^2 f}{\partial x^2}$$

#### (5) 混合偏导数

若二阶混合偏导数 $\displaystyle\frac{\partial^2 z}{\partial x \partial y}$ 和 $\displaystyle\frac{\partial^2 z}{\partial y \partial x}$ 都在区域 $D$ 连续，则：

$$\frac{\partial^2 z}{\partial x \partial y} = \frac{\partial^2 z}{\partial y \partial x}$$

---

### 3. 可微

#### 定义

全增量：
$$\Delta z = f(x_0 + \Delta x, y_0 + \Delta y) - f(x_0, y_0)$$

表示为：
$$\Delta z = A\Delta x + B\Delta y + o\!\left(\sqrt{\Delta x^2 + \Delta y^2}\right)$$

其中 $o\!\left(\sqrt{\Delta x^2 + \Delta y^2}\right)$ 表示比自变量增量更高阶的无穷小。那么称 $f$ 在 $(x_0, y_0)$ 处可微，并称 $A\Delta x + B\Delta y$ 为该点的全微分，记为 $dz$ 或 $df$。

$$dz = A\Delta x + B\Delta y = A\,dx + B\,dy$$

#### 可微的必要条件

若 $z = f(x, y)$ 在 $(x_0, y_0)$ 可微，则在该点的偏导数**存在**，且：

$$A = \frac{\partial z}{\partial x},\quad B = \frac{\partial z}{\partial y}$$

$$dz = \frac{\partial z}{\partial x}dx + \frac{\partial z}{\partial y}dy$$

#### 可微的充分条件

若 $z = f(x, y)$ 在 $(x_0, y_0)$ 的偏导数**存在且连续**，则在该点可微。

#### 判断可微的常用方法

- **① 定义法**：验证
  $$\lim_{\substack{\Delta x \to 0 \\ \Delta y \to 0}} \frac{\Delta z - A\Delta x - B\Delta y}{\sqrt{\Delta x^2 + \Delta y^2}} = 0$$

- **② 充分条件法**：若 $f'_x, f'_y$ 存在且连续，则函数必可微。

---

### 4. 多元函数的极值与最值

#### 极值定义

若存在点 $(x_0, y_0)$ 的邻域，使得任意一点 $(x, y)$ 满足：

$$f(x, y) \leq f(x_0, y_0) \quad \text{或} \quad f(x, y) \geq f(x_0, y_0)$$

则称 $(x_0, y_0)$ 为 $f(x, y)$ 的**极大值点**或**极小值点**。

> ⚠️ 注意：极值点不要求连续或可微。

## 二、多元函数微分法则

### 1. 链式求导法则

设 $f(u, v)$，$u = \varphi(x, y)$，$v = \psi(x, y)$，则 $z = f[\varphi(x, y), \psi(x, y)]$。

$$\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u} \frac{\partial u}{\partial x} + \frac{\partial z}{\partial v} \frac{\partial v}{\partial x}$$

$$\frac{\partial z}{\partial y} = \frac{\partial z}{\partial u} \frac{\partial u}{\partial y} + \frac{\partial z}{\partial v} \frac{\partial v}{\partial y}$$

**全导数**（若 $u, v$ 均只依赖于 $t$）：

$$\frac{dz}{dt} = \frac{\partial z}{\partial u} \frac{du}{dt} + \frac{\partial z}{\partial v} \frac{dv}{dt}$$

---

### 2. 全微分形式不变性

$$dz = \frac{\partial z}{\partial u}du + \frac{\partial z}{\partial v}dv$$

---

### 3. 隐函数存在定理（公式法）

#### 一元隐函数

$$\frac{dy}{dx} = -\frac{F'_x}{F'_y}$$

#### 三元隐函数

由 $F(x, y, z) = 0$ 确定 $z = z(x, y)$：

$$\frac{\partial z}{\partial x} = -\frac{F'_x(x, y, z)}{F'_z(x, y, z)}$$

$$\frac{\partial z}{\partial y} = -\frac{F'_y(x, y, z)}{F'_z(x, y, z)}$$

---

## 三、极值求解方法

### 1. 无条件极值

#### (1) 二元函数取极值的必要条件

若 $z = f(x, y)$ 在 $(x_0, y_0)$ 取极值，且偏导数存在，则：

$$f'_x(x_0, y_0) = 0,\quad f'_y(x_0, y_0) = 0$$

> ⚠️ 注：偏导数不存在的点也可能是极值点。

#### (2) 二元函数取极值的充分条件

记：
$$
\begin{cases}
f''_{xx}(x_0, y_0) = A \\[2pt]
f''_{xy}(x_0, y_0) = B \\[2pt]
f''_{yy}(x_0, y_0) = C
\end{cases}
$$

令判别式 $\Delta = AC - B^2$：

$$
\begin{cases}
\Delta > 0 \Rightarrow \text{极值} \begin{cases}
	A < 0 \Rightarrow \text{极大值} \\
	A > 0 \Rightarrow \text{极小值}
\end{cases} \\[6pt]
\Delta < 0 \Rightarrow \text{非极值} \\[4pt]
\Delta = 0 \Rightarrow \text{方法无效，需另作判断}
\end{cases}
$$

> 📌 注：$\Delta = AC - B^2 > 0$ 时，由 $AC > B^2 \ge 0$ 可知 $AC > 0$，故 $A$ 与 $C$ 必同号。

---

### 2. 条件最值与拉格朗日乘数法

对函数 $u = f(x, y, z)$ 在约束条件

$$
\begin{cases}
\varphi(x, y, z) = 0 \\
\psi(x, y, z) = 0
\end{cases}
$$

下的最值：

#### (1) 构造辅助函数

$$F(x, y, z, \lambda, \mu) = f(x, y, z) + \lambda\, \varphi(x, y, z) + \mu\, \psi(x, y, z)$$

#### (2) 求驻点

令各偏导数为零：

$$
\begin{cases}
F'_x = f'_x + \lambda \varphi'_x + \mu \psi'_x = 0 \\[2pt]
F'_y = f'_y + \lambda \varphi'_y + \mu \psi'_y = 0 \\[2pt]
F'_z = f'_z + \lambda \varphi'_z + \mu \psi'_z = 0 \\[2pt]
F'_\lambda = \varphi(x, y, z) = 0 \\[2pt]
F'_\mu = \psi(x, y, z) = 0
\end{cases}
$$
